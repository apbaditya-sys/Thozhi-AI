
# 🌸 Thozhi AI — Your Digital Welfare Companion

### Breaking Language and Literacy Barriers in Government Welfare Access

Thozhi AI is a multilingual, voice-assisted web application designed to help people discover government welfare schemes, understand eligibility requirements, prepare necessary documents, and access official application portals.

Developed as a prototype for **Hackarena**, Thozhi AI focuses on making welfare information more accessible to women, rural communities, senior citizens, and people who may have difficulty reading or navigating digital platforms.

---

## 🎯 Problem Statement

Many eligible citizens struggle to access government welfare schemes because of:

- Language barriers
- Limited digital literacy
- Difficulty understanding eligibility requirements
- Lack of awareness about available schemes
- Complicated application procedures
- Difficulty identifying the required documents

Thozhi AI aims to address these challenges through a simple, multilingual, and voice-assisted digital platform.

---

## 💡 Our Solution

Thozhi AI provides a user-friendly website where citizens can explore welfare schemes in their preferred language.

The platform combines multilingual navigation, voice guidance, scheme discovery, an interactive eligibility checker, and step-by-step application assistance.

Our goal is to make government welfare information easier to understand and access.

---

## ✨ Key Features

### 🌐 1. Multilingual Support

Users can choose their preferred language when they first visit the website.

Supported interface languages include:

- English
- தமிழ் — Tamil
- हिन्दी — Hindi
- తెలుగు — Telugu
- മലയാളം — Malayalam
- ಕನ್ನಡ — Kannada
- বাংলা — Bengali
- मराठी — Marathi

The selected language can be changed later.

### 🎙️ 2. Voice Assistant

A floating voice assistant helps users navigate the website.

Features include:

- Text-to-speech guidance
- Language-specific voice selection
- Adjustable speech speed
- Volume controls
- Voice preview
- Speech recognition where supported
- Read-aloud assistance

Voice availability and pronunciation quality depend on the browser and installed voices.

### 🔍 3. Welfare Scheme Explorer

Users can discover welfare schemes through searchable cards and category filters.

Scheme information may include:

- Scheme overview
- Eligibility criteria
- Benefits
- Required documents
- Application instructions
- Official government links

### ✅ 4. Eligibility Checker

An interactive questionnaire helps users understand whether they may satisfy a scheme's eligibility requirements.

The checker provides preliminary guidance and is not an official government eligibility determination.

### 📄 5. Document Checklist

Users can review the documents required for a scheme and track their preparation progress.

### 📝 6. Application Guidance

Step-by-step instructions help users understand how to apply for a scheme and locate the relevant official government portal.

### 📱 7. Responsive Design

The website is designed for desktop, tablet, and mobile screens, with accessible navigation and interactive components.

## 🚀 Getting Started

### Prerequisites

Install the following:

- Node.js
- npm
- Visual Studio Code
- Git

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/apbaditya-sys/Thozhi-AI.git
```

### 2. Open the Project

```bash
cd Thozhi-AI
```

Open the folder in Visual Studio Code.

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Website

Open the local URL displayed in your terminal.

For a standard Vite setup, this is usually:

```text
http://localhost:5173
```

## 🎤 How to Use the Voice Assistant

1. Open the Thozhi AI website.
2. Select your preferred language.
3. Click the voice assistant button in the bottom-right corner.
4. Select an available voice for your language.
5. Adjust the speaking speed if necessary.
6. Use the read-aloud or microphone features.

**Note:** Microphone access requires browser permission. Some languages may not have suitable voices installed on every device.
